# Tutorials

This directory contains a collection of tutorials and supporting material for the **sedExnerFoam** solver. The tutorials are intended to demonstrate the main capabilities of the model, from simple laminar sediment transport configurations to turbulent flow applications.

## Directory Structure

### `laminar/`

Tutorial cases involving **laminar flow conditions**. These examples provide a simple framework for understanding the coupling between hydrodynamics, sediment transport, and bed evolution.
- *1DSedim*: One dimensional settling of polystyrene particle. No mesh motion involved, the settling velocity reduces with the sediment concentration through an hindrance function.
- *movingBed1DSedim*: Another one dimensional settling case without hindrance effect, the sediment deposit on the sediment and the mesh motion so that the bed boundary always match the sediment bed position.

### `RAS/`

Tutorial cases using **Reynolds-Averaged Simulation (RAS)** turbulence models. These examples illustrate the application of `sedExnerFoam` to realistic hydraulic configurations where turbulence significantly affects sediment transport, suspension processes, bed evolution, and morphodynamic development.
- **MUSTE**: Sediment suspension in a laboratory flume under equilibrium conditions. No mobile sediment bed is considered and all particles remain in suspension throughout the simulation.
- **duneMigration**: Two-dimensional dune migration in a straight flume under steady flow conditions. The bed evolves freely and the dunes migrate downstream as a result of bedload transport.
- **duneMigration3D**: Three-dimensional counterpart of the *duneMigration* case. The computational domain is additionally discretized in the lateral direction, allowing the investigation of three-dimensional flow and bedform effects.
- **submergedJetScour**: Two-dimensional local scour downstream of a sluice gate. The high-velocity submerged jet impinges on an erodible bed located downstream of a rigid apron, leading to scour hole formation and development.
- **suspensionDev**: Two-dimensional development of sediment suspension downstream of a transition from a rigid bed to an erodible sediment bed. The case illustrates the progressive entrainment of sediment particles into the flow.
- **variableHeightDuct**: Three-dimensional dune formation and migration in a duct with variable height. The changing cross-section induces spatial variations in the flow field that influence sediment transport and bedform dynamics.

### `DATA/`

Experimental and reference datasets used for validation and comparison with numerical results generated by `sedExnerFoam`.

The datasets may include:

- bed elevation measurements,
- water surface profiles,
- sediment transport rates,
- velocity measurements,
- laboratory experiment descriptions.

### `PY/`

Python scripts and Jupyter notebooks dedicated to:

- post-processing simulation results,
- plotting and visualization,
- comparison with experimental data,
- sensitivity analyses,
- generation of publication-quality figures.

### `caseSedExnerFoam/`

A fully documented example case intended as a reference for `sedExnerFoam` users.

This tutorial provides:
- a complete case structure,
- a description of all required input files,
- explanations of solver-specific entries,
- examples of sediment transport and morphodynamic parameters,
- recommended practices for setting up new simulations.

## Getting Started

New users are encouraged to:

1. Run one of the cases in `laminar/`.
2. Explore the corresponding post-processing tools in `PY/`.
3. Compare results with the datasets provided in `DATA/`.
4. Review `caseSedExnerFoam/` for a detailed description of the solver inputs.
5. Move on to the more advanced turbulent cases contained in `RAS/`.

## Additional Information

For details regarding solver implementation, numerical methods, governing equations, and available sediment transport models, please refer to the main `sedExnerFoam` documentation.
